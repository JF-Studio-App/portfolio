Esta Política de Privacidade descreve como [SEU NOME OU NOME DA SUA EMPRESA] ("Nós", "Nosso" ou "nos") coleta, usa, armazena e protege as informações dos usuários ("Você") que utilizam nossos aplicativos móveis e serviços relacionados (coletivamente, o "Serviço").

Ao utilizar o Serviço, Você concorda com a coleta e o uso de informações de acordo com esta Política.

1. Tipos de Dados Coletados

Nós podemos coletar dois tipos principais de informações através do Serviço:

1.1. Informações Não Pessoais (Dados de Uso e Análise)

São dados que não identificam Você diretamente. Podemos coletá-los automaticamente sempre que Você utiliza o Serviço. Isso pode incluir:

  • Dados de Dispositivo: Modelo do dispositivo, tipo de sistema operacional (iOS/Android), identificadores únicos do dispositivo (que podem ser pseudônimos ou resetáveis), resolução de tela e informações da rede móvel.
  • Dados de Uso: Informações sobre como o Serviço é acessado e usado (ex: telas visualizadas, duração das sessões, recursos utilizados, desempenho do aplicativo, e registros de crash).
  • Dados de Localização Aproximada: Coletados através de endereços IP para fins de análise ou segmentação de anúncios, mas que não revelam a sua localização exata.

1.2. Informações Pessoais (Se aplicável – AJUSTE AQUI)

Se o Seu aplicativo exigir login ou interação direta, Você pode coletar informações pessoais. Se o seu aplicativo não coleta PII (Personal Identifiable Information), remova ou simplifique esta seção.

  • Exemplo: Se o aplicativo permitir login via e-mail, colete:
    • Endereço de e-mail.
    • Nome de usuário.
    • Identificador único de terceiros (ex: ID da Google ou Apple, se Você usar login social).

2. Como Usamos as Informações Coletadas

As informações coletadas são utilizadas para as seguintes finalidades:

  • Fornecer e Manter o Serviço: Para operar e entregar as funcionalidades do aplicativo.
  • Melhorar e Otimizar: Para entender como o Serviço é usado, identificar tendências, testar novos recursos e corrigir erros e falhas técnicas.
  • Comunicação: Para responder a solicitações, perguntas e fornecer suporte ao usuário (se Você coletar e-mail).
  • Publicidade (Se aplicável): Para exibir anúncios relevantes dentro do aplicativo, com base nos Dados de Uso e nas preferências de publicidade do Seu dispositivo.

3. Compartilhamento de Dados com Terceiros

Para operar o Serviço, nós utilizamos provedores de serviços terceirizados. Estes terceiros têm acesso aos Seus Dados de Uso apenas para executar tarefas em nosso nome e são obrigados a não divulgá-los ou usá-los para qualquer outra finalidade.

Os terceiros com quem podemos compartilhar informações incluem:

Categoria do Serviço Exemplo de Terceiro Tipo de Dados Compartilhados
Análise de Dados/Crash Reports Google Analytics, Firebase Dados de Uso e Dispositivo, sem identificação pessoal.
Publicidade (Se usar anúncios) Google AdMob, Facebook Audience Network Identificadores de publicidade do dispositivo e Dados de Uso.
Plataforma em Nuvem Amazon AWS, Google Cloud Informações de backend necessárias para a funcionalidade do app.

Nota sobre Publicidade: Se Você usa serviços de publicidade, os provedores podem usar os identificadores de publicidade do Seu dispositivo para personalizar os anúncios que Você vê.

4. Segurança dos Dados

A segurança dos Seus Dados é importante para Nós, mas lembre-se que nenhum método de transmissão pela Internet ou método de armazenamento eletrônico é 100% seguro. Embora nos esforcemos para usar meios comercialmente aceitáveis para proteger Suas informações, não podemos garantir Sua segurança absoluta.

5. Privacidade de Menores

Nosso Serviço não se destina a menores de 13 anos. Não coletamos intencionalmente informações de identificação pessoal de menores de 13 anos. Se Você for pai/mãe ou responsável e souber que Seu filho nos forneceu Dados Pessoais, entre em contato Conosco.

Podemos atualizar Nossa Política de Privacidade periodicamente. Notificaremos Você sobre quaisquer alterações publicando a nova Política de Privacidade nesta página e atualizando a data de "Última Atualização" no topo. Aconselhamos Você a revisar esta Política de Privacidade periodicamente para quaisquer alterações.
